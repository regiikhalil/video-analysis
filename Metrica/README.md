# Summary

SLG Surge's (whites) offensive transitions are driven by a compact 3-5-2 structure, with central midfielders initiating attacks and wing-backs providing width. Their man-to-man high press aims to force turnovers, allowing them to attack quickly before the opposition can reorganise. Following a regain, decisive forward passes and supporting runs exploit gaps in the opponent’s defensive line to create goalscoring opportunities.
